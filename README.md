# PriceAtlas

PriceAtlas is an open-source global price-intelligence platform that
collects, normalizes, matches, and historizes product prices across
countries.

## Initial Scope

- Countries: India, United States, United Kingdom
- Category: Smartphones
- Brands: Apple and Samsung
- Daily ingestion
- Historical price tracking
- Cross-country price normalization
- Canonical product matching

## Engineering Goals

PriceAtlas is designed around:

- Extensible source adapters
- Immutable raw data
- Idempotent ingestion
- Canonical product normalization
- Historical state tracking
- Automated data-quality validation
- Quarantine and replay
- Observable pipelines
- Automated testing and CI/CD
